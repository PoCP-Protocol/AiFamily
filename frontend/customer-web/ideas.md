# AiFamily 客户 Web 设计方向

## 三个方向

### 方向一

**Theme Name**：暖境流光

**Very Brief Intro**：以温暖家庭叙事包裹高反馈的成长内容流，让每次滑动都抵达一个可完成的小行动。借鉴短视频产品的单焦点节奏，但以安定、可信、非成瘾的体验取代刺激性消费。

**Probability**：0.04

### 方向二

**Theme Name**：成长手账剧场

**Very Brief Intro**：采用纸张、胶片与手账拼贴语言，把家庭照片、语音和成长记录组织成具有纪念感的章节。更偏情感收藏与亲子共创，游戏性来自收集和章节解锁。

**Probability**：0.07

### 方向三

**Theme Name**：家庭探索地图

**Very Brief Intro**：把成长路径构造成一张可探索的轻量世界地图，任务是节点，阶段是区域，成就是地标。空间感强、冒险感突出，但信息流效率低于前两者。

**Probability**：0.02

## 选定方向：暖境流光

### Design Movement

采用 **Humanist Digital × Kinetic Editorial × Calm Gamification**：以人文数字产品的温度为底，以编辑式大标题和沉浸式内容切换制造节奏，再用克制的游戏反馈增强行动完成感。它借鉴短视频框架的单焦点、上滑推进、即时反馈和无学习成本，但不复制黑色娱乐界面、无限消费或高刺激红点机制。

### Core Principles

第一，**一屏一意图**。主内容流每个视口只突出一个成长洞察、一项今日行动或一个家庭时刻，减少并列卡片造成的选择负担。

第二，**行动比浏览重要**。橙色始终代表可执行动作；任何沉浸内容都必须有明确的下一步、暂停点和退出路径，避免把家庭成长做成无限刷流。

第三，**结果可信且可解释**。蓝色承载导航、测评、专家与 AI 解释；绿色只在真实完成、连续进展和阶段达成时出现，绝不用作普通装饰。

第四，**多模态但不炫技**。文字、语音、图片、短视频都服务于“记录真实情境”，AI 输出明确标记为建议或草案，并保留来源、状态与家长确认入口。

### Color Philosophy

品牌色严格使用行动橙 `#F28C45`、信任蓝 `#2563EB`、成长绿 `#16866D`、深蓝文字 `#10213E`、暖白背景 `#FFF9F3` 和浅橙表面 `#FFF1E6`。视觉权重约为橙 60%、蓝 30%、绿 10%。橙色通过暖白、浅橙表面、橙色主按钮和进度光晕占据主导；蓝色构成导航、链接、可信标签和专业解释；绿色仅用于完成勾、成长里程碑与积极状态。禁止三色平铺和大面积绿色背景。

### Layout Paradigm

桌面采用**三轨沉浸布局**：左侧为稳定的家庭旅程导航，中间为窄而高的单焦点成长流，右侧为今日连续行动、家庭能量和快捷记录。中轨内容以 `min-height: 100dvh` 的章节式面板推进，不采用常见的居中营销页面。

移动端采用**纵向章节流 + 悬浮行动岛 + 五项底部导航**。内容章节接近一屏高度，但保留下一章节的视觉提示，避免用户失去方向。多模态记录以底部抽屉展开，确保单手操作。

### Signature Elements

第一，**成长光环**：由橙色主弧、蓝色可信刻度与绿色完成点组成，用于今日能量、连续行动和阶段里程碑；光环不是家庭评分，只表达已完成的行动进度。

第二，**呼吸胶囊**：多模态入口是一个会轻微呼吸的橙色胶囊，展开后呈现文字、语音、照片、视频四种输入，录音时转换为蓝色声波，提交完成时出现短暂绿色确认。

第三，**家庭轨迹带**：以非对称的柔性路径连接任务、复盘、成就和服务节点，形成“正在走一条路”的连续感，而不是积分商城式堆砌。

### Interaction Philosophy

所有高频操作应在 100–180ms 内给出物理反馈。完成任务时先确认动作，再展示经验与连续天数增长；重大阶段完成才出现全屏庆祝。内容流支持键盘、滚轮与触摸滑动，并提供显式“下一步”按钮，不把手势设为唯一入口。所有 AI 建议必须有“采纳”“调整”“暂不处理”三种可解释选择。

### Animation

章节进入使用 220ms 的透明度与 `translateY(12px)` 组合，采用 `cubic-bezier(0.23, 1, 0.32, 1)`；卡片组以 45ms 递增错峰。按钮按下缩放到 0.97，160ms 恢复。成长光环仅在数据变化时沿弧线推进，不持续旋转。录音声波随输入变化但限制振幅，避免视觉疲劳。成就解锁使用一次 480ms 的光点扩散和 260ms 徽章落位，之后完全静止。`prefers-reduced-motion` 下关闭位移、光晕和粒子，仅保留状态渐变。

### Typography System

情感性标题使用 **Noto Serif SC** 700，制造家庭叙事与陪伴感；界面正文和按钮使用 **Noto Sans SC** 400/500/700，确保中文可读性；进度数字、连续天数和时间使用 **Manrope** 700/800，强化精确和游戏反馈。一级页面标题为 40–56px，章节标题为 28–36px，正文为 15–17px，标签为 12–13px；绝不依赖全大写英文制造层级。

### Brand Essence

**为愿意一起成长的家庭，提供把理解变成每天一个小行动的可信空间。** 品牌人格：温暖、清醒、有行动力。

### Brand Voice

标题像一个理解家庭处境但不替家庭下结论的成长伙伴；CTA 直接、具体、可撤回；微文案承认困难并强调小步行动。禁止“立即改变孩子”“AI 精准诊断”“领先全网”等夸张表达。

示例标题：“今天，不解决所有问题。只把一件小事做好。”

示例 CTA：“用 3 分钟完成今天的家庭行动”

### Wordmark & Logo

标志采用一个由三段柔和轨迹形成的**家庭成长环**：橙色主轨代表共同行动，蓝色内弧代表理解与信任，绿色小芽点代表已发生的成长。中心负空间形成抽象的屋檐与拥抱，不使用现成爱心、房屋或人物剪影。字标在“Family”的连笔结构中嵌入一处向上的橙色笔势，不使用默认字体直接排字。

### Signature Brand Color

**行动橙 `#F28C45`** 是不可替代的品牌色。它不是警示红，也不是促销橙，而是代表“此刻能做的一件小事”。

## 多模态与前后端一致性决策

前端将四类输入统一建模为 `FamilyMomentDraft`：`TEXT`、`AUDIO`、`IMAGE`、`VIDEO`。浏览器端负责采集、预览、大小与格式校验；后端应负责上传签名、存储、转写、分析和 provenance。当前仓库尚无这些生产端点，因此本阶段提供完整交互和严格类型的 API 适配层；未配置 API 时进入明确标注的“体验数据模式”，不伪装成已完成的真实 AI 调用。

现有业务路径保持与 `FamilyApiClient` 一致：家庭首页映射 `GET /families/{family_id}/ui/01/home`，今日行动映射 `GET /families/{family_id}/growth/actions/today`，任务状态映射 `POST /families/{family_id}/tasks/{task_id}/state`，任务复盘映射 `POST /families/{family_id}/tasks/{task_id}/check-in`，测评入口映射 `GET /families/{family_id}/ui/02/assessment`。前端状态名沿用 `START`、`PAUSE`、`RESUME`、`CANCEL` 与 `COMPLETED`、`PARTIAL`、`NOT_COMPLETED`，不得自行创造与后端冲突的权威状态。

AI 输出在界面上只允许显示为 `DRAFT`、`Perspective` 或 `Recommendation`，并提供“由 AI 协助生成”“查看依据”和家长确认入口。成就系统只记录任务完成、连续行动和家庭共同参与，不生成家庭分数、孩子排名或诊断性标签。

## Web 场景工作空间决策

34 个移动端 UI 只作为需求证据。Web 不按 UI-01 至 UI-34 创建对应页面，而是按照家庭任务归并为八个工作空间：成长首页、理解家庭、成长计划、今日行动、家庭时光、专业支持、家庭互助、权益与家庭。

需要连续参与的今日行动、家庭记录和经审核经验流使用纵向沉浸框架；需要比较、回看、确认和编辑的测评、计划、服务与家庭档案使用双栏或多栏工作台。页面切换不按“上一个 App 页面/下一个 App 页面”组织，而按“触发—理解—确认—行动—复盘—支持—长期关系”的业务状态推进。

主导航采用两层结构。一级导航只保留“首页、理解、计划、支持、家庭”五个认知稳定的目的地；今日行动以全局橙色行动入口呈现，家庭时光与互助作为首页内容流和家庭工作空间的二级视图。任何业务状态都必须提供返回当前旅程的出口。

UI-11 的榜单、UI-08 的成长评分、UI-12/UI-29 的效果型成果表达、UI-17 的硬编码积分以及 UI-16 的伪购买语义均不搬运。它们分别被重构为自己的成长节奏、过程证据、隐私友好故事卡、可核验权益账本和参与意向。

## Style Decisions

桌面端核心路线统一使用三轨产品壳：左侧是稳定家庭旅程导航，中间是单焦点章节流，右侧是连续行动、成长光环和快捷记录。全页截图会隐藏固定两翼，但实际交互视图必须持续保留。

所有“开始、继续、预约、确认、完成”类主行动统一使用行动橙 `#F28C45`；深蓝只用于导航、依据、专业解释与可信边界，成长绿只在已完成或已解锁状态出现。

成就与进度的主视觉使用家庭轨迹带、成长光环和绿色完成点，不再以普通卡片网格作为主要组织方式。圆角白卡仅作为局部信息容器，不能替代章节与路径叙事。
