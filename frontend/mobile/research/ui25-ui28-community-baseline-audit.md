# UI-25 至 UI-28 社区内容循环基线复核

原始参考图来自既有 `platform-family-growth-vertical-slice-001` 分支，公开来源为 `https://github.com/PoCP-Protocol/Family/tree/platform-family-growth-vertical-slice-001`。四张参考图已经恢复到 `research/baselines/ui25-ui28/`，页面血缘固定为：UI-25 家长社区 → UI-27 家庭小记详情；UI-25/UI-28 → UI-26 发布家庭小记；UI-26 保存私有草稿后回到 UI-28。

## 既有 Family API 复用清单

现有权威契约位于独立 `family-ai` 仓库的 `packages/contracts/src/dev-platform-surfaces.ts`，实现位于 `apps/api/src/modules/family/dev-platform-surfaces.service.ts`。移动端继续通过 `GET /families/{familyId}/dev/platform-surfaces` 读取同一家庭范围投影，并使用既有受控 flow receipt 记录 no-op 交互，不建立新的社区后端、数据库或内容审核系统。

| 能力 | 既有字段或命令 | 移动端用途 |
|---|---|---|
| UI-25 内容目录 | `family_learning_exchange_feed` | 读取 `headline`、`introduction`、`entries[]`；每条包含 `exchange_ref`、`title`、`summary`、`topic` 和 `detail_route` |
| 内容事实边界 | `READING_EXPERIENCE_SUMMARIES_NOT_PUBLICATION_INTERACTION_OR_OUTCOME` | 明确内容只是家庭经验摘要，不是事实证明、公开互动或教育结果 |
| UI-25 目录命令 | `READ_SYNTHETIC_COMMUNITY_FEED` / `READ_ONLY` | 只读既有审核测试内容 |
| UI-26 草稿命令 | `ACK_SYNTHETIC_POST_DRAFT` / `NOOP_NOT_PERSISTED` | Family API 只返回无外部效果回执；正文保存在移动端家庭私有草稿 |
| UI-27 详情命令 | `READ_SYNTHETIC_POST_DETAIL` / `READ_ONLY` | 详情与互动展示保持只读；点赞、评论、举报不写入公共社区 |
| UI-28 我的社区命令 | `READ_SYNTHETIC_MY_COMMUNITY` / `READ_ONLY` | 只读私有内容与可见性边界；删除、撤回保持 no-op |

现有目录包含两条已审核测试经验摘要：`EXCHANGE_DIALOGUE_PAUSE`（亲子沟通，“给一次对话留一点停顿”）和 `EXCHANGE_READING_ROUTINE`（家庭阅读，“把共读放进睡前的十分钟”）。移动端可在 UI-27 展开为阅读友好的作者视角与来源说明，但不得虚构点赞数、评论数、粉丝数或专家背书。

## UI-25 家长社区

原始基线由顶部标题与搜索、推荐/成长打卡/家长吐槽/成果案例/同城圈子五个频道、蓝色家庭分享横幅、六个主题入口和纵向内容卡组成。内容卡包含作者、家庭阶段或角色标签、发布时间、主题、正文摘要、可选媒体格和点赞/评论/收藏入口。移动端必须保留“社区发现—主题入口—内容卡—详情/收藏—写小记”的层级，但不能把基线中的点赞或评论数字伪装成实时数据；没有服务端计数时使用无数字状态或明确的测试投影。

## UI-26 发布家庭小记

原始基线由成长打卡/成果展示/求助吐槽/经验分享四种类型、标题、正文、照片/视频入口、话题、挑战同步、顾问选择、今日任务提示和橙色发布行动组成。当前移动端在没有正式媒体上传、内容审核和公开发布契约前，只实现标题、正文、类型、话题与可见性设置，并保存家庭私有草稿；照片、视频、位置、顾问通知、公开发布和打卡写入均不得伪造。页面必须加入去标识化提示，禁止填写孩子姓名、学校、电话、地址和可识别照片说明。

## UI-27 家庭小记详情

原始基线由作者资料、家庭角色/等级标签、关注按钮、主题与正文、媒体格、点赞/评论/收藏/私聊顾问动作、评论列表和底部互动栏组成。移动端必须保留“作者视角—正文—来源/边界—其他家长观点—私有互动草稿”的结构，但作者小记和评论都只能作为 Perspective；顾问回应需要与普通家长观点分层。没有正式社区互动契约时，关注、点赞、评论、收藏和私聊均只记录本机家庭私有草稿，不增加公共计数、不发送通知、不联系顾问。

## UI-28 我的社区

原始基线由家庭资料头卡、粉丝/关注/积分、五项内容资产摘要、近 30 天动态、挑战进度、社区等级和权益组成。当前移动端必须保留“家庭资料—我的小记/草稿/收藏摘要—内容分组—写小记入口”的层级；粉丝、关注、积分、等级和挑战数字若没有既有服务器投影不得硬编码。页面统一回看私有小记草稿、收藏草稿和可见状态，不把本机草稿表述为已公开内容。

## 四页验收边界

| 页面 | 可读投影 | 移动端可写状态 | 禁止外部效果 |
|---|---|---|---|
| UI-25 | 经审核内容目录、主题、作者显示信息 | 收藏草稿、写小记入口 | 点赞计数、评论发布、关注通知 |
| UI-26 | 话题与可见性选项 | 家庭私有小记草稿 | 媒体上传、公开发布、位置、顾问通知 |
| UI-27 | 内容详情、作者视角、评论观点、来源边界 | 收藏/回应/关注私有草稿 | 公共互动写入、私聊、通知 |
| UI-28 | 家庭内容客户投影 | 草稿管理与继续编辑 | 伪造粉丝、积分、等级或公开状态 |

## Expo 移动运行态核对

已在 `390 × 844` 移动竖屏下实际渲染 `/ui/UI-25`、`/ui/UI-26`、`/ui/UI-27?exchangeRef=EXCHANGE_DIALOGUE_PAUSE` 和 `/ui/UI-28`。该尺寸为历史运行记录；后续布局调优统一使用 iPhone 16 Pro Max 逻辑视口 440×956。四页均保持白底、深蓝内容空间、行动蓝目录/详情、成长绿隐私状态和温暖橙写小记行动，符合三份 PPT 的 Warm Intelligence 视觉语言。

UI-25 已保留搜索、五频道、蓝色分享横幅、五主题入口、审核内容卡、收藏与写小记入口；UI-26 已保留四种小记类型、标题/正文、媒体说明、话题、可见范围和家庭行动关联；UI-27 已保留作者头卡、正文、主题视觉、来源边界、收藏/回应/返回社区和观点区；UI-28 已保留家庭内容空间、四项私有资产摘要、分组、成长营进度和写小记行动。

运行态没有展示虚构点赞、评论、粉丝、积分或社区等级；没有把本机草稿表述为已公开发布；“本机家庭体验已准备”等来源提示使用家长可理解的语言，没有在页面展示 Family API、fixture、synthetic 或 UI 编号等工程术语。
