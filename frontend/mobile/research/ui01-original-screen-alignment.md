原始首页由以下可见区域组成：顶部“家庭成长平台”与通知/更多入口；问候语和“今天也一起陪孩子成长”提示；大幅免费家庭测评横幅；六个快捷入口（AI诊断、21天挑战营、90天成长计划、成长案例、专家直播、家庭顾问）；“今日成长任务”三项清单及完成/去完成状态；“推荐内容/服务”横向内容卡；底部四项导航（首页、计划、社群、我的）。

## 后续 UI 目标取证

原始 Web 的热区分发代码表明：三条今日任务均进入 `growth-daily-task`；成长案例进入 `poster`；专家直播与家庭顾问均进入 `teacher-zone`；推荐卡均进入 `commerce-mall`。结合当前 legacy UI 注册表，采用以下目标映射：

| 原图热区 | 原始页面语义 | 当前目标 UI | 实施边界 |
| --- | --- | --- | --- |
| 免费家庭测评 | `assessment` | UI-02 | 首页只作入口。 |
| AI诊断 | `ai-report` | UI-03 | 首页只作入口。 |
| 21天挑战营 | `growth-camp-21` | UI-14 / UI-35 | 当前先进入 UI-14 相关商品详情；仍需确认是否增加直达 UI-35 的成长营体验入口。 |
| 90天成长计划 | `core-plan` | UI-04 | 首页只作入口。 |
| 成长案例 | `poster` / `growth-poster` | UI-12 | 首页只作入口。 |
| 专家直播、家庭顾问 | `teacher-zone` | UI-19 | 首页只作入口；直播关注回执由服务页处理。 |
| 三条今日任务 | `growth-daily-task` | UI-09 | 首页只显示任务清单和状态，所有任务热区进入统一任务页。 |
| 推荐内容/产品及更多 | `commerce-mall` | UI-13 | 首页只显示横向推荐卡，商品详情和意向由 UI-13/14 处理。 |

该映射以原始分发代码与现有 legacy UI 注册表为依据。当前五标签导航与原图四标签导航仍是独立架构差异，未获得用户确认前不改变。

## 高分辨率视觉参考

高分辨率原图确认：测评 Banner 使用明亮蓝色渐变、左侧三行白字和白色胶囊按钮、右侧四口家庭插画；六项入口为两行三列、白底且图标以青蓝/橙/绿/浅蓝/红橙分组；任务为三行紧凑白色清单；推荐内容/服务为三张横向等宽内容卡；底部为四等分导航。该参考图在本轮仅用于 UI-01 的结构、比例和视觉内容对照，不裁剪或伪装为当前可交互页面。
