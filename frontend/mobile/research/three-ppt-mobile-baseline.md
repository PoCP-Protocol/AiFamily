# 三份核心 PPT 的移动端产品与视觉基线

## 一、共同产品叙事

三份 PPT 从不同角度指向同一个产品方向：榜样教育不能停留在课程售卖，而要升级为持续经营家庭成长关系的平台；AI 不是首页卖点，而是用来把诊断、方案、任务、反馈、服务和复盘组织成连续体验的底层能力；平台价值最终来自可执行的产品、稳定交付、长期关系和可追溯数据。

| 核心材料 | 产品叙事 | 移动端主要用途 |
|---|---|---|
| 《榜样教育新商业模式》 | 从“一次课程成交”升级为“经营家庭成长的长期关系”；个人入口、三类核心产品和五类收入形成产品阶梯 | 首页、课程阶梯、会员权益、服务入口和资产回读 |
| 《榜样教育 AI 成长平台战略白皮书》 | 核心不是做 AI 教育工具，而是重构家庭成长服务；先把产品和交付做到极致，再由 AI 放大价值 | legacy UI 信息架构、交付标准、三年路线与功能优先级 |
| 《家庭教育大模型平台科技公司项目合作方案》 | 以平台、数据、跨端复用和流程自动化形成技术底座；强调赛道价值、商业闭环和合作机制 | AI 状态、数据血缘、系统能力、平台资产与运营后台的视觉表达 |

## 二、视觉语言

### 2.1 主体主题：Warm Intelligence

移动 App 的默认主题以第一、第二份 PPT 的浅蓝白和深蓝文字为主，形成“温暖、可信、清晰”的家庭成长体验。第三份 PPT 的深色科技主题只用于 AI 系统状态、数据血缘、报告解释和高级洞察，不作为全部页面的默认背景，避免家庭教育产品显得冷硬。

| 视觉角色 | 建议颜色 | 来源与用途 |
|---|---|---|
| 主背景 | `#F5F8FC` | 第一份 PPT 的浅蓝白背景；用于首页和大多数成长页面 |
| 内容背景 | `#FFFFFF` | 三份材料共同的高可读内容面；用于列表、表单和行动卡 |
| 主文字 | `#10213E` | 第一份 PPT 深蓝；用于标题与关键状态 |
| 品牌深蓝 | `#09295A` | 第一份 PPT 封面与主视觉；用于导航、强调和深色区 |
| 行动蓝 | `#2563EB` | 第二份 PPT 蓝色强调；用于主按钮和当前步骤 |
| 成长绿 | `#16A085` | 第三份 PPT 青绿色；用于进行中、连接和成长状态 |
| 温暖橙 | `#F28C45` | 第一份 PPT 的橙色点缀；用于“今晚一件事”和温暖提醒 |
| 阶段黄 | `#E9B949` | 第三份 PPT 黄色回路；用于计划节点和课程阶段 |
| AI 深色背景 | `#0A1628` | 第三份 PPT；仅用于 AI 解读、系统图和高级洞察 |
| AI 青色 | `#00A8E8` | 第三份 PPT；用于模型状态、数据来源和系统连接 |

### 2.2 版式转译

PPT 使用大量“标题 + 一句核心判断 + 表格/流程”的结构。移动端应转译为：顶部只保留一个当前问题或阶段判断；中部突出一个主行动；下部按需要展开解释、来源和其他入口。不能把 PPT 的宽表格直接缩进手机，而要转成分步列表、时间线或横向滚动的阶段标签。

| PPT 结构 | 移动端转译 |
|---|---|
| 一页一个战略判断 | 一屏一个主要任务或一个决策，不堆叠多个同权重模块 |
| 横向业务闭环图 | 顶部阶段进度 + 当前节点 + 下一步提示 |
| 多列能力表 | 分组列表或可展开条目，默认只显示最相关的一项 |
| 三年路线图 | 21 天、90 天、年度陪伴的纵向旅程时间线 |
| 深色科技方案页 | AI 解读页的局部深色“系统解释区”，显示来源和模型状态 |
| 深蓝封面页 | 启动页、课程阶段切换或会员里程碑的仪式性页面 |

## 三、legacy UI 的视觉分组

| 页面组 | UI 范围 | 默认视觉 | 特殊处理 |
|---|---|---|---|
| 家庭成长与计划 | UI-01~UI-12、UI-35 | 浅蓝白、深蓝文字、温暖橙行动 | UI-03/08 的 AI 解释区可使用深色科技面板 |
| 商业与权益 | UI-13~UI-18、UI-30、UI-32 | 白底、深蓝层级、成长绿权益状态 | 禁止电商促销式红色轰炸和焦虑倒计时 |
| 专家与服务 | UI-19~UI-24、UI-31、UI-34 | 白底、清晰头像/资质、行动蓝 | 真人服务状态与 AI 建议必须视觉分开 |
| 社区与内容 | UI-25~UI-28 | 温暖浅灰蓝、内容优先 | 儿童相关内容显示私有/待审核/已发布状态 |
| 家庭档案与结果 | UI-29、UI-33 | 高可读白底、时间线和来源标签 | 不使用总分、排名或诊断色阶 |

## 四、关键交互原则

1. 首页只突出“今晚一件事”，其他入口围绕它组织。
2. 所有推荐显示来源和性质，例如“规则建议”“课程建议”“家长视角”，不使用神秘的 AI 权威感。
3. 任务完成后的主反馈是“已记录这次行动”，而不是“家庭成长 +10”。
4. 21 天和 90 天计划使用阶段时间线，不使用惩罚式连续打卡火焰。
5. 会员、积分、邀请和续费仍完整开发，但用权益与资产语言表达，不把孩子问题做成促销压力。
6. 深色科技视觉只服务于解释数据来源、模型状态和系统连接，不能压过家庭场景与人的感受。
