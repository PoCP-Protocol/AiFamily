# UI-11 原图对齐记录：我们的成长节奏

## 原图依据

- 原图：`research/baselines/ui35-original/growth-ranking-reference-450x918.png`
- 原始函数：`growthRanking()`；该函数未提供热区，且原图存在家庭排名、积分与称号。

## 已确认差异与处理

| 原图视觉结构 | 安全替代 | 处理 |
|---|---|---|
| 本周/月/同城/同班级筛选 | 本周/本月/我的过程/可暂停 | 保留分段筛选视觉，删除跨家庭、同城和同班级比较。 |
| 冠军、亚军、季军三段高台 | 上周过程 / 我们的家庭 / 下次小目标 | 保留三段高台层级；中心只显示本家庭已记录次数。 |
| 家庭排名列表和积分 | 最近家庭过程 | 用已有同家庭事件投影替换，不显示分数、名次或他人家庭。 |
| “我的排名”“超过 82% 家庭”“成长行动家” | “我们的过程”“只和自己的过去比较” | 保留底部个人卡视觉，明确取消排名、百分位与称号。 |

## 保留边界

UI-11 只能比较同一家庭的过程，不显示跨家庭排名、百分位、积分或儿童/家庭称号。已有过程事件仍可进入 UI-12 整理为家庭私有故事。
