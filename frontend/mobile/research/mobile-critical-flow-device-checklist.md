# Family AI Mobile 真机关键行动流清单

本清单用于 iOS/Android 真机验证。请在 Expo Go 中打开当前开发预览，使用已配置的开发家庭会话或本机体验完成以下流程。每一项都应显示清晰的加载、成功或可恢复失败反馈；不应出现支付、公开发布、通知外发或自动履约。

| 流程 | 操作 | 预期结果 |
|---|---|---|
| 今日行动 | 从“今天”进入行动卡，完成一次打卡并返回首页 | 打卡回执可见，首页和成长回读同步更新；反思仅作为家庭私有记录。 |
| 家庭测评 | 进入家庭测评，完成题目并查看成长解读 | 测评进度、解读与阶段报告可回读；不出现儿童诊断、排名或总分。 |
| 21 天成长营 | 从首页进入成长营，完成当天行动后回到今日页 | 当日进度与阶段节奏一致，页面无内部编号或开发术语。 |
| 服务意向 | 浏览名师或活动，填写咨询/参与意向并返回服务记录 | 意向只保存为家庭私有草稿或受控开发回执；不产生真实预约或通知。 |
| 私有小记 | 写小记、提取标签、调整标签并在“我的社区”回读 | 标签可编辑，隐私提示生效；小记不公开发布。 |
| 下拉刷新 | 在商城、名师、社区、资产等列表下拉刷新 | 显示刷新反馈，远端投影或本机草稿重新读取；失败时保留已有内容并给出可理解提示。 |

## 回传方式

请记录每个流程的“通过 / 失败 / 异常表现”，并在出现异常时附上页面名称、操作步骤、系统版本和截图。不要在截图或消息中发送家庭账户 token、孩子身份信息或其他敏感资料。
