# UI-12 原图对齐记录：家庭私有故事卡

## 原图依据

- 原图：`research/baselines/ui35-original/growth-poster-reference-444x970.png`
- 原始函数：`growthPoster()`；唯一热区 `返回首页 → home`，原图其余分享/二维码内容仅作静态视觉展示。

## 已确认差异与处理

| 原图视觉结构 | 安全替代 | 处理 |
|---|---|---|
| 蓝色成果海报、孩子前后变化、连续打卡和成长值 | 家庭私有故事卡、当时/现在的家庭视角、过程片段数量 | 保留卡片层级；不声称儿童变化或量化成长结果。 |
| 徽章、二维码、分享给更多人、分享好友/朋友圈/海报 | 家庭小标记、仅家庭可见、保存故事/继续编辑/回到节奏 | 保留底部视觉节奏；无二维码、系统分享、公开发布或通知。 |
| 海报标题和个人资料 | 家庭私有记录和来源清楚的过程片段 | 不显示儿童姓名、年龄、学校或家庭可识别信息。 |

## 保留边界

故事只由已有同家庭过程事件和家庭视角构成，保存为本机私有草稿。它不构成成长成果证明，不产生外部效果。
