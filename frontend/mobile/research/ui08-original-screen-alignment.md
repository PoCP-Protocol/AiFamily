# UI-08 原图对齐记录：家庭过程回顾

## 原图依据

- 原图：`research/baselines/ui35-original/ui18/growth-02-ai-report.png`
- 原始函数：`growthReport()`；原图热区 `生成个性化方案 → core-plan`，当前实现改为 `查看可选支持方案 → UI-04`

## 已确认差异与处理

| 原图 | 原实现 | 对齐处理 |
| --- | --- | --- |
| 蓝色家庭成长报告头、头像、记录时间与报告编号 | 阶段回顾标题和行动流水列表 | 保留蓝色头部结构；统一使用“家庭过程回顾 / 家庭私有记录”表达，不显示儿童姓名。 |
| 五维雷达与中心总分 | 三项统计卡 | 恢复五维图结构，但中心只显示“过程回顾 / 待确认”，不显示总分或家庭排名。 |
| 优势、风险、优先建议三条色带 | 深蓝证据边界面板 | 保留三条色带结构，并改为“已看见的行动 / 继续观察 / 下一步可试”。 |
| 7 天、30 天、90 天推荐成长路径与底部生成方案 | 行动流水和“查看 90 天成长方案” | 保留路径视觉，但改为“可选行动路径”；底部出口进入 UI-04 的可选支持方案。 |

## 保留边界

原图中的数值雷达、综合分和“风险”不作为儿童诊断或家庭结论呈现。当前页面使用过程状态与来源清楚的建议；反思/行动记录不被自动解释为结果。
