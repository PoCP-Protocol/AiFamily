# UI-06 原图对齐记录：会员与我的

## 原图依据

- 原图：`research/baselines/ui35-original/mine-member-reference-434x1124.png`
- 原始函数：`coreMine()`；补充菜单/权益出口依据：`mine()`、`member()`

## 已确认差异

| 原图确认结构 | 原实现 | 对齐处理 |
| --- | --- | --- |
| 顶部为“我的”，深蓝会员信息卡、邀请权益、六项功能列表和年度会员横幅 | 实现为“我的陪伴服务”，展示服务卡、私有打卡草稿和过程提示 | 彻底移除陪跑服务结构，重建会员与我的页面。 |
| 会员卡展示头像、年度会员、陪伴天数、成长积分、家庭等级和亲子币 | 仅展示服务旅程摘要 | 复用会员/商业投影的积分、权益和订阅状态，保留原图统计位置。 |
| “邀请 3 个家庭”浅金卡和“去邀请”行动 | 无邀请权益区 | 映射到 UI-15 邀请有礼，不在当前页发送邀请。 |
| 报告、计划、订单、邀请、成长档案、客服六项列表 | 无对应入口 | 分别只导航至既有 UI-08、UI-04、UI-32、UI-15、UI-33、UI-19。 |
| 年度会员服务横幅和“查看权益” | 无会员横幅 | 映射到 UI-30 年度陪伴方案；不在当前页开通、续费或扣款。 |

## 保留边界

页面只读取现有会员、商业权益与本机邀请草稿。它不改变会员状态、不扣款、不自动续费、不外发邀请、不直接创建客服工单；所有菜单只进入后续已注册 UI。

## S6 场景与 4A 对齐

| 架构视角 | UI-06 当前处理 |
| --- | --- |
| BA | UI-06 属于 S6“会员、积分、订单与资产”中的“我的会员中心”只读入口；用户可查看会员卡、邀请权益、菜单入口和年度服务横幅，但本页不完成开通、续费、扣款、权益发放或客服建单。 |
| DA | 会员状态、成长积分、可用权益和商业资产来自 `MembershipProjection`、`MembershipPlansProjection`、`CommerceCustomerProjection`；邀请进度只读取本机 `invitationDraft`。缺失投影时显示 `0`、`家庭成长陪伴记录待同步`、`有效期待确认` 或 `会员服务待确认`。 |
| AA | 保留原图的深蓝会员卡、浅金邀请卡、六项菜单和年度服务横幅；菜单只导航到 UI-08、UI-04、UI-32、UI-15、UI-33、UI-19，查看权益导航到 UI-30。 |
| TA | 页面只调用 `getMembershipPlans`、`getMembershipCustomerProjection`、`getCommerceCustomerProjection`；不调用支付、订单提交、服务预约、外部通知或模型生成接口。 |
