# UI02 免费家庭测评五主题研究底稿

## 研究定位

UI02 免费家庭测评不是儿童诊断、能力测验、家庭排名或效果预测。它是 L0 层的家庭支持需要确认工具：帮助监护人把当下最想获得支持的家庭场景说清楚，并把后续 UI03 家庭成长解读、UI04 计划草稿、UI09 日常行动卡连接起来。

因此，五个主题必须同时满足四个条件：

1. 家庭中可观察，而不是对孩子人格下结论。
2. 能转化为低风险家庭支持行动，而不是临床处置。
3. 有理论或权威指南支撑，不来自单一内部经验。
4. 有明确边界，不能推断智力、心理疾病、成瘾、家庭好坏或教育效果。

## 证据与实践来源分层

| 来源 | 证据/用途 | 使用边界 |
| --- | --- | --- |
| Harvard Center on the Developing Child: Executive Function resources | 执行功能和自我调节涉及计划、注意、切换、任务管理，可由环境支持发展 | 作为学习习惯、自律能力的理论支撑；不能诊断执行功能障碍 |
| CASEL SEL framework | SEL 涵盖管理情绪、建立关系、负责决策，并强调 school-family-community partnership | 作为情绪管理、亲子沟通、自律能力的教育框架支撑；不能当作测评量表常模 |
| CDC Essentials for Parenting | 家长资源覆盖情绪命名、连接沟通、规则例行、回应行为，强调非一刀切、给家长可用资源 | 作为家庭实践支持；主要面向幼儿家庭，跨年龄使用时只取原则，不外推效果 |
| AAP HealthyChildren Media guidance | 儿童媒介环境需要父母监测并帮助解释外部影响 | 作为手机与边界主题支撑；不使用“手机成瘾”诊断语言 |
| Family 知识库 MD-001 / CN-001 / CN-002 | 情绪教练式回应、被听见感、强制/防御互动循环已有证据卡与边界 | 用于亲子沟通与情绪主题的内部方法化，不夸大为必然有效 |
| 波波校长/Family 内部实践资料 | “今晚一件小事”“先接住再行动”“低剂量陪伴”的产品化表达 | 仅 E1 内部/品牌实践，不可证明效果，只能转化交互和服务节奏 |

## 五主题研究结论

### 1. 学习习惯

**主题定义**：家庭情境中，孩子启动、维持、完成学习任务时获得结构支持的情况。

**理论支撑**：学习任务启动、计划拆分、注意维持和任务收尾与执行功能/自我调节有关。Harvard executive function resources 将计划、注意、切换和任务管理视为可发展能力，并强调环境支持。CDC parenting resources 中的 routines and rules 支持把家庭例行与规则作为具体实践入口。

**实践支撑**：家长端可以从“固定开始仪式”“任务拆成第一小步”“完成后简短收尾”入手，减少单纯催促。实践目标是建立可重复的家庭学习节奏，不是判断孩子学习能力或成绩原因。

**UI02 可观察信号**：作业启动、困难坚持、家庭学习节奏。

**题目意图**：

| 题目 | 观察对象 | 不能推断 |
| --- | --- | --- |
| 开始写作业前常需要反复提醒 | 任务启动是否依赖外部催促 | 懒惰、智力、学习障碍 |
| 遇到稍难题目容易拖延、分心或放弃 | 困难恢复和坚持情况 | 学习能力差、态度差 |
| 家里缺少稳定学习开始、休息和收尾节奏 | 家庭结构支持是否清晰 | 家庭教育失败 |

**后续支持方向**：学习例行、任务拆分、低剂量复盘、家长催促语言替换。

### 2. 情绪管理

**主题定义**：孩子情绪触发、表达、恢复，以及家长共同调节支持的家庭互动情况。

**理论支撑**：CASEL SEL 把 manage emotions 纳入社会情绪学习核心能力。CDC parenting resources 提供 noticing and naming emotions 的家长实践方向。Family 知识库 MD-001 引入情绪教练式回应，并记录 TinT 相关证据，但产品必须收窄为“支持方向”，不声称一次回应带来确定效果。

**实践支撑**：家长端可以先命名情绪、暂停冲突、用一句承接替代立刻纠正。目标是提高家庭共同调节的机会，而不是判断孩子心理疾病或气质类型。

**UI02 可观察信号**：恢复时间、冲突暂停、家长回应策略。

**题目意图**：

| 题目 | 观察对象 | 不能推断 |
| --- | --- | --- |
| 情绪上来后需要较长时间恢复 | 情绪恢复时间和支持需求 | 心理疾病、情绪障碍 |
| 亲子冲突中难以先暂停再说 | 共同调节与冲突暂停 | 家长或孩子有问题 |
| 孩子表达焦虑、生气或委屈时家长不确定如何回应 | 家长回应策略需求 | 家长无能、孩子脆弱 |

**后续支持方向**：情绪命名、暂停脚本、冲突后修复、人工支持提醒。

### 3. 亲子沟通

**主题定义**：孩子是否愿意表达、家长是否能倾听，以及冲突后关系修复的家庭循环。

**理论支撑**：CASEL 强调 supportive relationships；CDC parenting resources 包含 connecting and communicating；Family 知识库 CN-001、CN-002 将被听见感和防御/强制互动循环作为可观察构念，MD-001 给出“先连接再纠正”的低风险实践。

**实践支撑**：亲子沟通主题应把问题放在互动循环里，而不是归因给孩子不愿沟通或家长不会教育。产品可提供复述、少讲道理、冲突后修复三类行动。

**UI02 可观察信号**：表达意愿、讲道理/纠正循环、冲突修复。

**题目意图**：

| 题目 | 观察对象 | 不能推断 |
| --- | --- | --- |
| 孩子不太愿意主动和家长说 | 沟通入口是否通畅 | 孩子封闭、关系已坏 |
| 对话容易变成讲道理、纠正或争执 | 沟通循环是否升级 | 家长错误、孩子叛逆 |
| 冲突后较少重新和好、复盘或修复 | 修复机制是否存在 | 家庭关系结论 |

**后续支持方向**：今晚怎么说、倾听练习、关系修复卡、冲突复盘。

### 4. 手机依赖

**主题定义**：数字设备使用对睡眠、作业、家庭节奏与亲子规则协商的影响。

**理论支撑**：AAP HealthyChildren Media guidance 认为儿童每天面对大量媒介信息，需要父母监测并帮助解释。该主题应命名为家庭中的“手机与边界/设备使用情境”，当前基线使用“手机依赖”时，必须在题目和边界中避免成瘾诊断。

**实践支撑**：产品可帮助家庭建立清楚、共同执行的媒介规则：时间、地点、睡前边界、替代活动和家长一致性。重点不是把手机问题归咎于孩子，而是看规则是否清楚、冲突如何发生、家庭执行是否一致。

**UI02 可观察信号**：日常功能干扰、围绕设备冲突、规则一致性。

**题目意图**：

| 题目 | 观察对象 | 不能推断 |
| --- | --- | --- |
| 手机或平板影响作业、睡眠或家庭安排 | 设备使用对日常功能的干扰 | 成瘾、意志薄弱 |
| 围绕手机经常讨价还价或冲突 | 规则执行中的亲子冲突 | 孩子不自律 |
| 手机规则不清楚或标准不一致 | 家庭边界清晰度与一致性 | 家庭管理失败 |

**后续支持方向**：家庭媒介规则、睡前边界、协商脚本、替代活动。

### 5. 自律能力

**主题定义**：孩子在家庭支持下参与计划、执行、检查和复盘的自我管理过程。

**理论支撑**：Harvard executive function resources 支持将计划、注意和任务管理理解为可发展能力；CASEL 将 responsible decision-making 与 goal achievement 纳入社会情绪能力；因此“自律”在 UI02 中应表达为自我管理支持，而不是意志品质评价。

**实践支撑**：家长端可以从“让孩子参与制定计划”“一起确定检查方式”“完成后复盘方法”开始。实践重点是从全程监督转向逐步交还参与权。

**UI02 可观察信号**：监督依赖、自主参与、方法复盘。

**题目意图**：

| 题目 | 观察对象 | 不能推断 |
| --- | --- | --- |
| 日常任务比较依赖家长全程监督 | 外部监督依赖程度 | 孩子懒惰、意志差 |
| 较少参与制定计划、目标或检查方式 | 自主参与机会 | 自主能力低 |
| 没做好时忙着催促补救，较少复盘方法 | 反思与策略调整机会 | 家庭没有方法 |

**后续支持方向**：计划共创、检查清单、复盘问题、逐步放手。

## UI 与后端设计约束

1. UI02 展示层只能说“最想先支持哪一方面”“最近两周观察”，不能说“诊断结果”“孩子问题类型”“能力等级”。
2. 每个主题必须有 operationalDefinition、observableSignals、boundary、questions、researchSupport、practiceSupport。
3. 每道题必须有 intent 和 evidenceAnchor；`NOT_SURE` 必须是合法选项，避免强迫家庭下结论。
4. 提交数据应写入 versioned assessment response，不直接写 Family Fact 或核心 Ontology。
5. UI02-result 只能输出家庭自查结果和支持方向，不生成分数、排名、诊断或确定性改进承诺。
6. 后续若引入 AI 解读，必须经 Model Gateway，并把 Perspective / Hypothesis / Recommendation / Decision / Action 分层。

## 2026-08-24 工程落地状态

- 五主题模型已落到 `family-assessment-capability-memory.ts`：每个主题包含 operationalDefinition、theorySupport、practiceSupport、observableSignals、boundary、nextSupportDirections 和 3 道带 intent/evidenceAnchor 的题目。
- 每个主题已补充 dataSupport：明确记录哪些家庭视角观察、这些数据只能用于支持方向/资源匹配/题项改进，以及哪些诊断、评分、排名或儿童标签不能产生。
- 免费测评已登记为家庭教育智能平台 S2 场景能力，平台对象包括 AssessmentTool、AssessmentSession、AssessmentResponse、FamilyNeed、SupportDirection 和 ConsentReceipt。
- UI02 的深追题答案已同步写入本地 `assessmentAnswers`，同时保留远端 versioned assessment response 提交流程。
- UI02-result 已通过 `buildUi02AssessmentResultSummary()` 从主题模型和已保存答案生成结构化摘要，显示观察项完成度、观察信号、支持方向、理论依据、数据支持、实践支持、平台衔接和非诊断边界。
- 平台衔接链路为 UI02 免费家庭测评 → UI02-result 测评结果 → UI03 家庭成长解读 → UI04 90 天计划草案 → UI09 日常行动卡；AI 只能做家庭视角整理、资源匹配和下一步建议草案。
- `ui02-assessment-baseline.test.ts` 已覆盖模型完整性、结构化结果摘要、数据支持、平台集成、提交链路、非诊断边界和结果页显示契约，当前为 11/11 通过。

## 当前缺口与下一步

- 当前五主题已能支撑 UI02 v2 免费测评系统，并已成为家庭教育智能平台 S2 场景能力；但多数外部依据是权威指南/框架，不能当作量表效度证明。
- 若未来要把 UI02 从“家庭支持需要确认”升级为正式测评工具，需要补充：量表来源、题项效度、信度、适用年龄、中文家庭样本、人工审核规则。
- “手机依赖”是基线标题，为避免诊断化，代码内的 operationalDefinition 必须坚持“DEVICE_USE_CONTEXT / 设备使用情境”，展示文案如需改为“手机与边界”应走 UI 基线评审。
