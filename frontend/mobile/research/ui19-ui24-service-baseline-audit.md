# UI-19 至 UI-24 专家服务循环基线复核

## 全局约束

UI-19 至 UI-24 属于 legacy UI 中的服务循环，必须延续三份核心 PPT 的 **Warm Intelligence**：白底和浅蓝背景、深蓝专业层级、行动蓝主按钮、温暖橙强调。真人服务状态必须与 AI 建议视觉分开；移动端只做原生展示、家庭私有草稿和投影适配，不另建服务业务逻辑。

原始参考图来自既有 `platform-family-growth-vertical-slice-001` 分支，已经恢复到 `research/baselines/ui19-ui24/`。页面血缘固定为：UI-19 专家发现 → UI-20 专家说明 → UI-21 咨询需求；UI-22 活动目录 → UI-23 活动说明；两条路径最终在 UI-24 回看。

公开来源为 `https://github.com/PoCP-Protocol/Family/tree/platform-family-growth-vertical-slice-001`。六张参考图原路径位于 `50_开发_dev/apps/web/public/bangyang-reference/`；正式服务契约原路径为 `50_开发_dev/apps/api/src/modules/orchestration/family-service-booking.contract.ts`。

## UI-19 名师专区

原始基线的模块顺序为：顶部返回、标题与更多入口；搜索框；深蓝咨询横幅；六个热门领域；推荐名师列表；底部五项导航。每位名师卡包含头像、姓名、专业身份、服务方向、评分、服务家长数量、查看详情和立即咨询。

移动端必须保留搜索、六主题入口、专业横幅、推荐专家卡和双行动。评分、服务数量与“名师认证”不能作为未经后端验证的事实；在现有测试数据模式下应改为“服务资料”“可了解方式”等来源透明语言。专家排序不得呈现为 AI 对家庭的决定。

## UI-20 名师详情

原始基线的模块顺序为：顶部返回与分享；深蓝专家头卡；评分、服务家长数量和好评率；老师介绍；擅长领域标签；日期与时段选择；家长评价；底部文字咨询与橙色一对一预约。

移动端必须保留专家头卡、三项摘要、专业介绍、领域标签、可了解时间、家庭评价区和双行动栏。测试数据中的资历、评分、评价只能标为服务资料或体验内容，不能伪装成已核验资格事实；“预约”按钮只进入咨询需求草稿，不占用真人时段、不发送通知、不支付。

## UI-21 在线咨询预约

原始基线使用四步进度条组织“选择方式—选择时间—填写信息—确认预约”。页面包含文字、电话、视频和线下面对面四种咨询方式；日期与时段；孩子年龄、核心问题和期望目标；服务协议勾选；底部蓝色确认按钮和咨询须知。

移动端保留四步结构、四种方式、时间偏好和家庭需求描述，但不收集孩子姓名、电话或精确住址。年龄只保留粗粒度阶段；问题描述是家长的 **Perspective**，不是孩子诊断。确认按钮仅保存家庭私有咨询需求；连接同一 Family API 时，可使用已存在的可用时段和幂等 booking request，但仍不表示真人已确认、不支付、不通知。

## UI-22 沙龙活动

原始基线的模块顺序为：顶部返回与更多；蓝色家庭沙龙横幅；城市选择与搜索；全部、亲子沟通、学习习惯、情绪陪伴、家庭关系等主题筛选；三张活动卡；底部导航。每张卡包含活动图片、主题标签、名称、日期时间、城市地点、剩余名额和查看详情。

移动端必须保留横幅、城市/主题筛选、活动列表密度、日期地点和详情入口。活动数据优先复用 UI-22 `family_growth_activity_catalog`；城市、时间、地点等未由投影提供的字段只能使用明确标记的现有体验资料。剩余名额不能伪装成实时库存，进入详情不代表报名。

## UI-23 活动详情

原始基线的模块顺序为：顶部返回与分享；活动大图；主题标签、标题和副标题；日期时间、城市地点、剩余名额；三项活动亮点；五段活动流程；适合人群；参与收获；底部价格、咨询活动与橙色报名按钮。

移动端必须保留活动主视觉、三项摘要、亮点、流程、适合家庭和双行动栏。活动亮点与参与收获应描述活动内容，不承诺家庭或孩子变化；价格和剩余名额只有在同一 Family API 返回时才能呈现为当前数据。橙色主行动只保存家庭私有活动了解意向，不报名、不写日历、不发送通知。

## UI-24 我的咨询与活动

原始基线的模块顺序为：顶部“我的”；家庭头像、家庭称谓、等级与会员标签；咨询、活动、收藏和成长积分四项摘要；“我的咨询”卡片；“我的活动”卡片；深蓝会员年卡；底部五项导航。咨询和活动条目包含人物/活动缩略图、服务类型、时间、状态与下一步按钮。

移动端必须保留家庭资料摘要、四项统计、咨询分组、活动分组、状态标签和会员服务横幅。所有数量优先取同一 Family API 客户投影；没有数据时显示空状态，不伪造已服务次数。预约需求、服务记录和活动意向均为家庭私有过程；“已完成”只表示记录状态，不代表服务效果或教育结果。

## 既有 Family API 复用清单

| 能力 | 路径 | 关键字段与边界 |
|---|---|---|
| 服务供给目录 | `GET /families/{familyId}/orchestration/test-loop/services/offerings?page_id=UI-19` | `offerings[]` 包含服务引用、版本、标题、提供者显示名、服务主题、年龄参考、下一可了解时间、渠道和可用状态；只返回已准入教师测试供给；`external_effect=false` |
| 可用时段 | `GET /families/{familyId}/orchestration/test-loop/services/slots?service_offering_ref=...&service_offering_version=...` | `slots[]` 包含时段引用、开始/结束时间、VIDEO/TEXT/OFFLINE 渠道和 AVAILABLE/RESERVED 状态 |
| 咨询需求 | `POST /families/{familyId}/orchestration/test-loop/services/booking-requests` | 请求只提交 `page_id`、服务引用、版本、时段引用和最小 attributes；必须带幂等键；回执 `external_effect=false`；不接收儿童敏感内容、通知对象或提供者资格 |
| 服务回看 | `GET /families/{familyId}/orchestration/test-loop/services/customer-projection` | `visibility=FAMILY_PRIVATE`；`bookings[]` 状态为 DRAFT/REQUESTED/CONFIRMED/CANCELLED/EXPIRED；`service_records[]` 状态为 PENDING/SCHEDULED/CANCELLED/COMPLETED |
| UI-22 活动目录 | `GET /families/{familyId}/dev/platform-surfaces` | UI-22 卡片内 `family_growth_activity_catalog`；活动浏览不代表报名、出席或结果 |

服务供给还包含一条只读专家直播测试投影：主题为家庭沟通，状态为 SCHEDULED/LIVE/ENDED，且 `fixture_only=true`、`external_effect=false`。移动端可展示和保存关注草稿，但不进入真实直播。
