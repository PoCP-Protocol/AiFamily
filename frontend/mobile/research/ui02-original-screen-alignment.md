# UI-02 原始测评画面对齐记录

## 已观察的原始画面

基线图 `core-02-assessment.png` 与 `family-assessment-step2-reference.png` 表示同一家庭测评步骤。它们均显示：顶部返回、居中“家庭测评”标题、右侧更多/圆形图标；“第 2 / 5 步”文字和五分之二蓝色进度条；主问题“您孩子目前最需要改善的问题是？”及“（单选）”说明；五张带彩色图标的主题卡；可选补充信息区；底部全宽蓝色“下一步”行动按钮。

## 已确认的原图功能点

| 功能点 | 原图表现 | 当前核对要求 |
| --- | --- | --- |
| 测评进度 | 第 2 / 5 步、蓝色进度条 | 进度必须随当前步骤更新，不能仅为装饰。 |
| 单选主题 | 学习习惯、情绪管理、亲子沟通、手机依赖、自律能力 | 选择状态用蓝色描边和勾选反馈；每步只能选一项。 |
| 补充信息 | 年龄/阶段、家庭情况、孩子性别 | 明确标为可选；选择状态可见且可修改。 |
| 下一步 | 固定在内容底部的主行动 | 未完成必填选择时不应伪造完成；完成后进入下一题或后续既有 UI。 |
| 解读出口 | 测评完成后离开测评页 | 必须进入既有成长解读 UI-03，而不在 UI-02 复制解读。 |

## 尚待与当前实现比较的事项

当前 UI-02 的题目模型、每题单选限制、补充信息、进度计算、保存动作以及完成后的 UI-03 跳转仍需通过源码与运行态逐项核对。未经原图或现有后续 UI 取证，不新增诊断、排名、总分或儿童结论。

## 当前实现决策（2026-08-24 更新）

早期对齐记录曾认为三道深追题应从 UI-02 首屏移除，仅保留原图的五主题单选步骤。该判断已被后续产品要求覆盖：免费家庭测评的五个主题必须有深入的理论支持、实践支持、观察信号和边界，不能只是随意主题标签。

因此当前 UI-02 的保留原则是：原图的顶部结构、进度、五主题单选、补充信息和“下一步”主动作继续作为视觉基线；三道深追题作为 `FAMILY_SUPPORT_NEEDS/v2` 的研究支撑扩展，用于把主题选择落到可观察家庭情境，不输出孩子评分、排名、诊断或临床判断。

当前代码与测试已将该决策固化为契约：`ui02-assessment-baseline.test.ts` 要求五主题都包含 `operationalDefinition`、`theorySupport`、`practiceSupport`、`observableSignals`、`nextSupportDirections`、边界和题目意图；研究底稿见 `ui02-five-theme-family-assessment-research.md`。年龄/阶段、家庭情况和孩子性别仍是当前页可编辑的补充信息；远端保存只能通过既有版本化测评 Named Action，不伪装为直接写入家庭档案。
