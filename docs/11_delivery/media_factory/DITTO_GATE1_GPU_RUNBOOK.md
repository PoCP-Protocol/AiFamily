# Ditto Gate1 GPU Runbook (FAMILY-MEDIA-003)

> Delivery procedure for the **first real neural** Famili avatar smoke.
> This is **not** Current Truth for product readiness. Current local machine:
> GPU_GATE=FAIL (e.g. GT 730 / 2GB) → use a remote Linux Nvidia node.

## 1. Goal

Produce:

`FAMILI_DITTO_GATE1_R01.mp4`

from:

`STATIC IMAGE (FAMILI_V2_IDENTITY_MASTER_R01)` + `FIXED AUDIO (FAMILI_RDH_SMOKE_AUDIO_V0)`

via **official** Ditto neural inference — not mux, Canvas, fixture, or rule mouth.

Agents must **not** purchase cloud GPUs or bind payment methods.

## 4. Engine isolation

Keep Ditto **outside** the AiFamily worktree:

```text
export DITTO_ENGINE_ROOT=/opt/aifamily-engines/ditto-talkinghead
export DITTO_MODEL_ROOT=$DITTO_ENGINE_ROOT/checkpoints
export DITTO_PYTHON=$DITTO_ENGINE_ROOT/.venv/bin/python   # or conda `ditto`
export DITTO_DEVICE=cuda
```

Do **not** dump Ditto CUDA/Torch into AiFamily `pyproject.toml`.

## 5. Install

```bash
git clone https://github.com/antgroup/ditto-talkinghead "$DITTO_ENGINE_ROOT"
cd "$DITTO_ENGINE_ROOT"
git checkout c3e47eee2e626500017a0556b470d6d4182f85e8
conda env create -f environment.yaml
conda activate ditto
git lfs install
git clone https://huggingface.co/digital-avatar/ditto-talkinghead checkpoints
```

Confirm layout includes `ditto_pytorch/` and `ditto_cfg/v0.4_hubert_cfg_pytorch.pkl`.

## 7. Inference command (PyTorch)

```bash
cd "$DITTO_ENGINE_ROOT"
"$DITTO_PYTHON" inference.py \
  --data_root "$DITTO_MODEL_ROOT/ditto_pytorch" \
  --cfg_pkl "$DITTO_MODEL_ROOT/ditto_cfg/v0.4_hubert_cfg_pytorch.pkl" \
  --audio_path /path/to/FAMILI_RDH_SMOKE_AUDIO_V0.wav \
  --source_path /path/to/FAMILI_V2_IDENTITY_MASTER_R01.png \
  --output_path ./FAMILI_DITTO_GATE1_R01.mp4
```

Or invoke AiFamily adapter once env vars + GPU_GATE=PASS:

```text
provider_id=ditto via BenchmarkRunner (execution_target=REMOTE_GPU_NODE)
```

## 8. Post-run validation

1. `ffprobe` → video + audio streams, duration > 0, readable fps/resolution, frame_count > 1  
2. Sample multiple timestamps; if frames identical → `STATIC_VIDEO_SUSPECTED=true` (Gate1 media fail)  
3. Record `artifact sha256` in `provenance.json`  
4. `human_review.json` → `status=PENDING_HUMAN_REVIEW` — **never** auto `gate1=PASS`
