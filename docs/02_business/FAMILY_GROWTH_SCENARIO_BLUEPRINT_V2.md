# AiFamily 家庭成长场景蓝图 V2

> 本文件是重组评审稿，不是已接受的产品决策。它把蓝图从“技术模块列表”改写成“家庭完成了什么”。PMO 接受后，才替代旧场景计划成为当前执行基线。

## 1. 产品主线

AiFamily 的第一价值不是展示 AI，而是帮助家长完成一次有意义的家庭成长循环：

```text
家长带着真实困扰进入
  → 被准确理解
  → 看见一份可讨论的家庭解释
  → 家长确认真正要解决的重点
  → 形成有依据的成长方案
  → 在日常中实践并留下观察
  → 复盘变化与阻碍
  → 必要时获得知识、专家或服务支持
```

每个场景必须有一个明确的家庭主结果。页面、AI、API、数据库和测试都围绕这个结果组织。

## 2. MVP 场景地图

| 场景 | 家长要完成的事 | 主结果 | 进入条件 | 退出证据 | 负责人 |
|---|---|---|---|---|---|
| S1 首次理解 | 把“家里最近发生的事”说清楚，并确认平台对重点的理解 | `GrowthIntent` | 已登录家庭、有效测评工具 | 可回读测评证据、解释、家长确认记录 | 首达小队 |
| S2 家庭成长循环 | 把确认的重点变成计划，在真实生活中实践并复盘 | `JourneyPlan` + `PracticeRecord` + `PhaseReview` | S1 已确认意图 | 新会话回读、幂等、观察/阻碍/复盘证据 | 成长循环小队 |
| S3 知识与 AI 陪伴 | 在家庭需要的上下文中得到有依据的解释和下一步选择 | `Perspective`/`Recommendation` 草案 | S1/S2 提供证据和知识引用 | 知识引用、模型版本、人工/家长确认轨迹 | AI/知识小队 |
| S4 专业服务承接 | 家长明确需要时找到合适服务并完成一次可追踪履约 | `ServiceCase` / `DeliveryRecord` | 家长主动表达需要并确认 | 预约、履约、反馈、补救链证据 | 服务小队 |
| S5 家庭关系网络 | 在家庭愿意的范围内获得家庭间经验与活动连接 | 受控 `FamilyInteraction` | 家长主动加入主题或活动 | 可见范围、审核、撤回、举报/处置证据 | 关系网络小队 |
| S6 会员与购买 | 基于已表达的家庭需要选择并购买解决方案 | `OrderIntent` / `Entitlement` | 家长主动确认方案 | 价格/权益/履约/退款状态可回读 | 价值转化小队 |

小橘灯专家直播是独立产品队列，不作为 AiFamily MVP 的前置依赖；它只通过 AiFamily Platform Core 的身份、家庭范围、授权、审计和服务接口汇报。

## 3. 场景设计原则

### 3.1 先问家庭发生了什么，再给解释

首页入口、测评和知识内容都从家长的真实困扰开始。不得先给抽象标签、榜单或泛化的 AI 结论。家长每一步都能回答：平台看到了什么、为什么这样理解、我是否同意继续。

### 3.2 测评不是分数，AI 不是裁判

测评的维度用于组织理解、发现关系和形成讨论材料；AI 输出是可核对的观点或建议草案。家长确认的是“这个方向是否描述了我们现在要处理的事”，不是接受机器诊断。

### 3.3 每个场景都必须闭合正向与反向路径

正向路径说明家庭如何得到结果；反向路径说明未完成、拒绝、撤回、过期、跨家庭、重复请求、服务失败时，用户看到什么、如何恢复、系统留下什么证据。没有反向路径的页面不得算完成。

### 3.4 技术支援不拥有场景结果

Platform Core、AI Gateway、数据库、前端和 QA 是支援角色。每个场景由一个 DRI 对用户结果负责，不能以“接口已完成”替代“家长完成了事情”。

## 4. 统一场景状态模型

```text
事实 Fact
  → 解释 Perspective（可追溯证据）
  → 建议 Recommendation（可选择）
  → 家长/人工确认的 Action
  → 可观察记录与阶段复盘
```

场景之间只通过明确的 receipt/contract 交接，不跨场景读取内部表，不把 AI 草案直接写成家庭事实。

## 5. 第一阶段成功标准

第一阶段不是“所有页面都有占位符”，而是至少一个合成家庭能运行 S1→S2，并在同一个产品体验中看见 S3 的知识依据；同时 S4 有真实服务履约链可复用，S5/S6 完成可执行 PRD 与最小接口契约。

必须展示的用户结果：

1. 家长完成测评后能看到与自己的描述相连的解释，而不是空泛总结。
2. 家长确认后能看到为什么形成这份成长计划，以及引用了哪些知识。
3. 家长记录一次真实生活观察，重新打开后仍能看到自己的过程。
4. 家长可以说“这不是我的重点”、撤回或暂停，系统不会伪造完成。
5. 当家庭需要外部帮助时，平台能从已确认需要进入服务选择，而不是强行推销。

## 6. 非目标

第一阶段不做家庭总分、家庭排名、儿童商业画像、自动诊断、自动高影响决策、无限信息流、无授权公开互动或把合成数据伪装成生产能力。小橘灯的直播媒体能力也不进入本阶段依赖图。
