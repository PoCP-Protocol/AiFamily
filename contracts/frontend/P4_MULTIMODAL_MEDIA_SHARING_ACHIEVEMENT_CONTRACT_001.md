# P4 多模态媒体、家庭分享与成长成就合同

本合同是 P4 的可验收目标，不是当前能力证明。实现必须通过合同测试后，才能把对应能力标为可用。本合同只覆盖 Experience/Multimodal 的媒体、家庭内容分享和成长成就体验；不改变 Journey、Membership、Contribution、FGCN 或共享 Registry 的所有权。

## 1. 领域对象必须分开

`MediaAsset` 是原始媒体引用；`MediaTranscript` 是从媒体派生的转写结果；`MediaEvidence` 是绑定来源的成长/关系/贡献证据。三者不可用一个宽泛的媒体对象互相替代：

- `MediaAsset` 不存供应商对象或内联原始二进制，只保存受控存储引用、原始媒体元数据和派生删除索引。
- `MediaTranscript` 必须引用一个 `MediaAsset`，拥有自己的来源、版本、模型尝试、留存和删除句柄；删除原始媒体必须能定位并删除转写。
- `MediaEvidence` 必须引用一个或多个来源，保留观察与确认状态；AI 草稿不能直接成为权威事实、诊断、结果或商业资格。

每个对象都必须带 `tenant_id`、`family_id`、`subject_ids`、明确 `purpose`、`consent_version`/有效窗口、`retention.expires_at`、`deletion.deletion_id`、来源/版本和 correlation/causation。用途、主体或同意版本不匹配时必须拒绝读取、派生、分享和成就投影。

## 2. 家庭内容分享

分享默认是 `FAMILY_PRIVATE`，只允许同一租户、同一家庭内的成员或已核验的家庭成人邀请；禁止公开分享、跨家庭读取、伪造收件人、绕过内容审核和用分享扩大原始媒体的留存期限。分享请求必须是幂等的，并经过对象授权、目的同意、适龄安全检查和人工/策略审核。

涉及儿童主体时：

- 请求者必须是有权限的监护人；儿童内容不能成为广告、带货、打赏、画像推荐、收益或排名依据。
- 内容必须通过适龄和安全审核；审核未完成、拒绝或撤回后，分享必须失败关闭。
- 原始媒体删除、同意撤回或留存到期必须级联撤销分享及其派生转写/证据；保留不可变审计事实，不保留可播放原文。

成人家长/创作者可以另行进入受审核的成人贡献流程；本合同不把儿童曝光、成绩、情绪、粉丝、点赞或播放时长变成权益/结算条件，也不自动授予现金。

## 3. 成长成就与游戏化

成就只能由可追溯的行动完成、暂停后返回、关系反馈、复盘或经审核的成人贡献证据触发。每个成就必须带 `evidence_refs`、同意与删除链路、家庭私有可见性和幂等键。

成就不得由播放/刷屏时长、点赞、粉丝、连续登录、公开排名、家庭总分、孩子成绩、情绪或商业转化触发；不得暴露跨家庭比较。撤回或删除来源后，投影必须撤销可见派生数据并保留删除审计证明。

## 4. 验收矩阵

| 场景 | 必须结果 |
| --- | --- |
| 三种对象的正向创建 | 每种对象独立校验来源、目的、同意、主体、留存和删除链路 |
| 缺同意/过期/撤回 | 读取、派生、分享和成就投影均拒绝；无部分提交 |
| 跨租户/跨家庭/跨主体 | 统一拒绝且不泄露对象是否存在 |
| 分享审核绕过 | `PENDING`/`REJECTED`/失效审核不能建立分享 |
| 删除原始媒体 | 转写、证据、分享和缓存引用全部进入删除态，可回读删除证明 |
| 幂等冲突 | 相同请求重放返回同一结果；同键不同载荷返回冲突；不得重复奖励 |
| 重启回读 | 新进程只从持久化投影读到授权范围内的记录；不以本地内存恢复权限 |
| 成就反作弊 | 播放时长、点赞、排名、总分和商业转化不能触发成就 |
| 成人创作者权益 | 仅在成人身份、审核、真实贡献验收完成后进入独立权益/结算合同；儿童主体不参与商业计价 |

## 5. 当前缺口

当前 Experience runtime 暴露的是合并式 `ExperienceMediaRef`，尚未提供本合同要求的三个独立对象、分享状态机或删除级联投影。对应实现接入前，验收测试应保持红色证据，不得通过测试夹具或 `create_all` 把缺口伪装成生产能力。
